=========================================
  부각이 - 데스크탑 고양이 + 뽀모도로 타이머
=========================================

[ 실행하기 ]
  "고양이_실행.vbs" 를 더블클릭하면 끝입니다.
  설치할 것도, 깔아야 할 프로그램도 없어요. (윈도우 전용)

  ※ 안 켜지면 "RUN.bat" 을 더블클릭해 보세요. (같은 기능의 대체 실행 파일)

[ 컴퓨터 켤 때 자동으로 나오게 하기 ]
  "AutoStart.bat" 을 더블클릭하면 부팅 시 자동 실행이 켜집니다.
  같은 파일을 다시 더블클릭하면 꺼집니다. (켜기/끄기 토글)

  · 지금 상태를 알려주고 물어본 뒤에 바꾸니까 실수로 켜질 일은 없어요.
  · 폴더를 다른 곳으로 옮기면 연결이 끊깁니다.
    옮긴 뒤에는 AutoStart.bat 을 두 번 실행(해제 -> 재등록)해 주세요.

[ 바탕화면에 바로가기 만들기 ]
  "고양이_실행.vbs" 우클릭 -> "바로 가기 만들기" ->
  생긴 파일을 바탕화면으로 끌어다 놓으면 됩니다.
  (아이콘을 바꾸려면 바로가기 우클릭 -> 속성 -> 아이콘 변경 ->
   같은 폴더의 "부각이.ico" 선택)

[ 부각이랑 놀기 ]
  · 몸통이나 머리를 왼쪽 클릭  ->  쓰다듬기 (앞발로 꾹꾹이를 해줍니다)
  · 궁댕이(엉덩이)를 클릭      ->  궁디팡팡 (꼬리 번쩍 들고 좋아합니다)
  · 아무데나 오른쪽 클릭       ->  궁디팡팡
  · 부각이를 누른 채로 끌기    ->  원하는 위치로 옮기기 (놓으면 그 자리에 멈춤)
  · 마우스를 부각이 근처로 가져가면
      - 눈동자가 커서를 따라 움직이고
      - 몸을 낮추고 노려보다가
      - 앞발을 쭉 뻗어 커서를 낚아챕니다 (핑크 젤리가 보여요)

[ 부각이가 혼자 하는 것 ]
  걷기 / 앉기 / 앞발로 세수 / 기지개 / 하품 / 꾹꾹이 / 가끔 꼬리 툭 튕기기
  가끔 눈이 동그랗게 커집니다.

[ 뽀모도로 타이머 ]
  작업표시줄 오른쪽 아래 트레이의 고양이 아이콘을 우클릭하세요.
    - 집중 시작   : 집중 시간 동안 부각이가 식빵을 굽고 졸며 기다립니다
    - 휴식 시작   : "야옹" 하고 울고, 밥그릇이 나타납니다
    - 시간 설정   : 집중/휴식 시간을 원하는 분 단위로 직접 정할 수 있어요
                    (25/5, 50/10, 15/3 빠른 선택 버튼도 있습니다)
    - 크기 조절   : 부각이가 너무 크거나 작으면 여기서 바꾸세요
                    아주 작게 / 작게 / 보통 / 크게 / 아주 크게
                    "화면에 맞게 자동"을 누르면 지금 모니터에 맞춰 다시 계산합니다
    - 타이머 정지
    - 부각이 재우기 : 종료

  휴식 시간에 밥그릇을 클릭하면 사료가 쌓이고, 부각이가 고개를 숙여 먹습니다.
  안 주면 부각이가 중간중간 "야옹" 하고 보챕니다.
  설정한 시간과 크기는 settings.txt 에 저장돼서 다음에 켜도 그대로입니다.

[ 크기가 이상할 때 ]
  모니터 해상도나 윈도우 배율(125%, 150% 등)이 사람마다 달라서
  처음 켤 때 화면 높이에 맞춰 자동으로 크기를 정합니다.
  그래도 마음에 안 들면 트레이 아이콘 우클릭 -> "크기 조절" 에서 바꾸세요.

[ 다른 사람에게 주기 ]
  이 폴더를 통째로 압축해서 주면 됩니다. 받은 사람은 압축을 풀고
  "고양이_실행.vbs" 를 더블클릭하면 바로 부각이가 나옵니다.

[ 안 켜질 때 - 위에서부터 순서대로 해보세요 ]

  1) 파란 보안 경고창이 뜬 경우
     "추가 정보" -> "실행" 을 누르세요.
     (인터넷에서 받은 파일이라 처음 한 번 뜹니다)

  2) 더블클릭해도 아무 반응이 없는 경우
     "RUN.bat" 을 더블클릭해 보세요.
     회사 PC나 백신 프로그램이 .vbs 파일 실행을 막는 경우가 많습니다.

  3) 압축을 풀지 않고 ZIP 안에서 바로 실행한 경우
     반드시 압축을 먼저 풀어야 합니다.
     ZIP 안에서 실행하면 스크립트 파일을 못 찾아서 조용히 종료됩니다.

  4) 파일 이름이 깨져 보이는 경우 (예: ъ쒖뼇씠_떎...)
     압축 프로그램이 한글 이름을 깨뜨린 것입니다.
     이때도 "RUN.bat" 은 영문 이름이라 정상 동작합니다.

  5) 파일 속성에 "차단 해제" 체크박스가 있는 경우
     CatPet.ps1 우클릭 -> 속성 -> 아래쪽 "차단 해제" 체크 -> 확인

  6) 그래도 안 되면
     시작 메뉴에서 "Windows PowerShell" 을 열고 아래를 붙여넣어 보세요.
     (에러 메시지가 그대로 보여서 원인을 알 수 있습니다)

        powershell -ExecutionPolicy Bypass -File "폴더경로\CatPet.ps1"
